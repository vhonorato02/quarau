# 0011 — Internacionalização preparada (pt padrão, en/es desligados)

- **Status:** aceita · **Data:** 2026-10-05

## Decisão

- `next-intl` com `localePrefix: 'as-needed'`: português sem prefixo (URLs atuais preservadas), `/en` e `/es`
  habilitáveis por `NEXT_PUBLIC_ENABLED_LOCALES=pt,en,es` no build.
- Payload com `localization` (`pt`, `en`, `es`, fallback para `pt`): campos de texto marcados como `localized`.
- Mensagens de interface em `src/i18n/messages/{pt,en,es}.json` (en/es ainda com o texto em português).

## Consequências

Para lançar o inglês: traduzir as mensagens, preencher o conteúdo `en` no CMS e incluir `en` na variável.
